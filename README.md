Sobre o projeto
O Sistema de Biblioteca tem como objetivo
auxiliar no controle de livros, alunos,
empréstimos e devoluções.
## Objetivo
Desenvolver um sistema que permita
gerenciar o acervo da biblioteca.
## Público-alvo
- Bibliotecários
- Funcionários
- Alunos
## Funcionalidades
- Cadastro de livros
- Cadastro de alunos
- Empréstimo de livros
- Devolução de livros
- Consulta de livros
- Relatórios
## Equipe
- Aluno 1
- Aluno 2
- Aluno 3
